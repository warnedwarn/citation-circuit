# Citation Circuit interface identity

This product is navigated as a map. Documents are positioned nodes, verified relations are routes, and the primary visual question is spatial: what points to what? Its editorial serif, dotted field, overlapping cards, route lines, and lower map composer must not be reused as a generic project shell.

The core browser journey is `create map -> attach two permissionless edges -> seal -> inspect graph`. It has no score, countdown, winner, or yes/no verdict.
